# /research - 抖音赛道调研分析

## 描述
对抖音短视频赛道进行深度调研分析，包括赛道对比、竞品拆解、关键词挖掘，输出结构化调研报告。

## 使用方式
- `/research` — 全赛道对比调研，推荐最适合入局的赛道
- `/research {赛道名}` — 对指定赛道进行深度调研
- `/research 竞品 {账号名或关键词}` — 竞品账号分析
- `/research 关键词 {赛道}` — 该赛道的热门关键词挖掘

## 执行流程

### 1. 读取项目上下文
- 读取 `CLAUDE.md` 了解当前账号定位（如已有）
- 读取 `data/research/` 已有调研报告避免重复

### 2. 数据收集
使用 WebSearch 搜索以下信息：
- 搜索"抖音 {赛道} 2026 趋势 数据"获取赛道整体情况
- 搜索"抖音 {赛道} 头部账号 粉丝"获取头部玩家信息
- 搜索"抖音 {赛道} 变现 收入 案例"获取变现数据
- 搜索"抖音 {赛道} 新手入局 建议"获取入局难度评估
- 搜索"抖音热门话题 {赛道}"获取热门关键词

如果是全赛道对比，需调研以下主要赛道：
- 知识/教程、情感/心理、影视解说、美食、搞笑/段子、音乐、游戏、生活/Vlog、母婴、三农、宠物、健身

### 3. 分析与评估
对每个赛道从以下维度评分（1-5分）：
- **变现潜力**：能赚多少钱
- **增长空间**：赛道天花板高不高
- **竞争程度**：竞争激烈程度（分越低竞争越小越好）
- **入局门槛**：入局难度（分越低越容易越好）
- **自动化适配**：适合AI图文/混剪等自动化程度

### 4. 输出报告
- 按 `templates/research-report.md` 模板格式输出
- 保存到 `data/research/YYYY-MM-DD-{主题}.md`
- 如果是全赛道对比，在报告末尾给出明确的 **Top 3 推荐赛道** 及理由

### 5. 更新建议
- 如果调研结论明确，建议用户更新 `CLAUDE.md` 中的账号定位部分
- 提示用户下一步可以使用 `/topic` 基于调研结果生成选题

## 输出格式
严格按照 `templates/research-report.md` 模板输出，确保每个字段都有内容。

## 注意事项
- 数据要尽量引用具体来源
- 分析要客观，不要过度美化任何赛道
- 重点关注"高收益 + 可自动化"的赛道组合
- 如果搜索结果不足，要标明"数据有限，建议进一步验证"
