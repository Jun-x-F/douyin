# /script - 视频脚本编写

## 描述
根据选题生成完整的视频脚本，支持 AI图文、混剪、二创、口播四种形式，输出可直接用于制作的结构化脚本。

## 使用方式
- `/script {选题标题}` — 从选题库匹配选题并生成脚本（自动匹配视频类型）
- `/script {类型} {主题}` — 指定类型生成脚本（类型：AI图文/混剪/二创/口播）
- `/script 优化 {脚本路径}` — 优化已有脚本
- `/script 批量` — 为选题库中所有 backlog 状态的选题生成脚本

## 执行流程

### 1. 确定选题和类型
- 如果用户给了选题标题，在 `data/topics/backlog.json` 中查找匹配
- 如果找到，使用选题库中记录的 type 确定视频类型
- 如果未找到或用户直接指定主题，根据内容特征推荐最适合的类型
- 如果用户明确指定了类型，使用用户指定的类型

### 2. 读取上下文
- 读取 `CLAUDE.md` 获取账号风格、内容规范
- 读取对应的模板文件：
  - AI图文 → `templates/script-ai-graphic.md`
  - 混剪 → `templates/script-mashup.md`
  - 二创 → `templates/script-recreation.md`
  - 口播 → `templates/script-oral.md`
- 如有相关调研报告，读取参考

### 3. 脚本生成

#### 通用规则（所有类型）
- **开头钩子**（0-3秒）：必须强力抓住注意力
  - 悬念型："你知道吗？90%的人都不知道这个..."
  - 反差型："月薪3000的我，靠这个方法赚了10万"
  - 共情型："每次加班到深夜，你是不是也想过..."
  - 提问型："为什么有些人怎么吃都不胖？"
- **节奏**：信息密度高，每5-8秒一个新信息点
- **结尾**：必须有互动引导语
- **时长**：默认 30-60 秒（除非用户指定）

#### AI图文类型特殊要求
- 每个分镜的"画面描述"要足够详细，能直接用于 AI 生图 prompt
- 画面描述用英文书写（适配主流 AI 生图工具）
- 配音文本要口语化，适合 TTS 朗读
- 建议 5-8 个分镜

#### 混剪类型特殊要求
- 素材关键词要具体可搜索
- 标注剪辑节奏变化（快切/慢放/正常）
- 转场方式建议

#### 二创类型特殊要求
- 明确标注原片来源和使用片段
- 改编要有新视角/新解读
- 注意版权风险提示

#### 口播类型特殊要求
- 文案口语化，避免书面语
- 标注表情和动作提示
- 提供提词器格式的连贯文本

### 4. 输出脚本
- 严格按对应模板格式输出
- 保存到 `content/scripts/YYYY-MM-DD-{标题}.md`
- 同时在终端展示脚本全文

### 5. 更新状态
- 如果选题来自选题库，将该选题状态更新为 `in-progress`
- 提示用户下一步可以使用 `/material` 采集素材（P1 实现后）

## 脚本优化模式

当用户使用 `/script 优化` 时：
- 读取指定脚本文件
- 从以下维度评估并给出改进建议：
  - **钩子强度**：开头是否足够吸引人
  - **信息密度**：是否有冗余内容
  - **节奏感**：剪辑节奏是否合理
  - **互动性**：是否有评论引导
  - **完播率预估**：观众会在哪里流失
- 输出优化后的完整脚本（覆盖原文件或保存为新版本）

## 注意事项
- 脚本质量是整个流水线的核心，要花最多心思在这里
- 每个脚本都要有明确的"情绪曲线"（起-承-转-合）
- 避免说教感，用故事和案例代替道理
- 数据和案例要具体（"去年增长了300%" 比 "增长很多" 好）
- 钩子不能标题党，要和内容匹配
