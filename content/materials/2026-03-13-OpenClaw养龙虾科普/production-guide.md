## 第二步：TTS配音

### 推荐方案：剪映TTS（最简单）
1. 打开剪映 → 新建项目（9:16竖屏）
2. 点击"文本" → "智能朗读"
3. 将 `tts-text.txt` 的内容分段粘贴
4. 推荐音色：**浩宇**（科技感男声）或 **云希**（清晰干练）
5. 语速调整为 **1.1-1.2倍**（教程类需要偏快节奏）
6. 注意 `tts-text.txt` 中的标记：
   - `...` = 停顿0.3-0.5秒
   - `【加重】` = 提高音量/降低语速
   - `【放慢】` = 语速降至0.9倍
   - `【兴奋】` = 语速加快+升调
   - `【语气转严肃】` = 分段录制，切换更低沉的语调

### 备选方案：Edge TTS（命令行免费）
```bash
# 安装
pip install edge-tts

# 生成配音（晓晓-中文女声）
edge-tts --voice zh-CN-XiaoxiaoNeural --file tts-text.txt --write-media audio/voiceover.mp3

# 或用云希-中文男声
edge-tts --voice zh-CN-YunxiNeural --rate="+10%" --file tts-text.txt --write-media audio/voiceover.mp3
```

### 配音要求
- 总时长控制在 **85-90秒**（留5秒给片头片尾缓冲）
- 语速：约 **220字/分钟**
- 全文约 330 字，对应90秒刚好合适

## 第三步：获取配乐BGM

### 方案A：剪映音乐库（最方便）
在剪映中搜索以下关键词：
- "科技感" / "数码" / "教程BGM" / "轻快科技"
- 选择 120-130 BPM 的曲目


## 第四步：剪映组装

### 4.1 项目设置
- **画布**：9:16 竖屏
- **分辨率**：1080 × 1920
- **帧率**：30fps

### 4.2 导入素材
按以下顺序拖入时间线：

```
时间线轨道排列（从上到下）：

轨道4 [字幕]  ████ SRT字幕导入 ████████████████████████████████
轨道3 [配乐]  ♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪♪
轨道2 [配音]  ▓▓▓▓ TTS配音文件 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
轨道1 [图片]  |场景0|  场景1  |   场景2   |   场景3   | 场景4  | 场景5  | 场景6 |
              0s   3s      15s        30s        45s      60s     75s     90s
```

### 4.3 图片时长设置
1. 选中每张图片，调整展示时长匹配上表
2. **关键**：根据实际配音时长微调，确保画面切换与配音内容同步

### 4.4 图片动效（Ken Burns 效果）
每张图片都要加动效，避免"PPT感"：

| 场景 | 推荐动效 |
|------|---------|
| 场景0 钩子 | 快速放大推入（1.0→1.15），制造冲击感 |
| 场景1 是什么 | 缓慢上移（从下半部分移到上半部分），引导视线 |
| 场景2 能干嘛 | 缓慢放大（1.0→1.08），聚焦细节 |
| 场景3 为什么火 | 缓慢缩小（1.1→1.0），展示全貌 |
| 场景4 怎么用 | 缓慢上移，从底部金字塔移到顶部 |
| 场景5 风险提醒 | 微微震动/抖动效果，营造紧张 |
| 场景6 结尾 | 静态居中，稳定感 |

### 4.5 转场效果
- 场景之间使用 **"叠化"（Cross Dissolve）** 转场，时长 0.3-0.5秒
- 场景4→场景5（怎么用→风险提醒）使用 **"闪白"** 转场，制造反转感
- 不要用花哨转场，保持专业感

### 4.6 字幕设置
1. 导入 `subtitles.srt` → 剪映会自动识别时间码
2. 字幕样式：
   - **字体**：思源黑体 Bold / 阿里巴巴普惠体
   - **大小**：48-52px（手机端清晰可读）
   - **颜色**：白色主体 + 2px黑色描边
   - **位置**：画面底部 20% 处
   - **重点词**：手动变为黄色或红色加粗
3. 校对字幕，修正断句和时间对齐

### 4.7 音量调节
- **配音**：100%（主音轨）
- **BGM**：20-25%（不盖过配音）
- BGM在风险提醒段（1:00-1:15）可以切换为紧张感更强的段落或降低音量
